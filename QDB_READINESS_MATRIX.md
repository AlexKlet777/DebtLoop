# DebtLoop — QDB START Readiness Matrix

This file is an internal readiness tracker for the Startup Qatar Investment Program START track.

| QDB START criterion | Current DebtLoop evidence | Status | What is still needed |
|---|---|---|---|
| Unmet market need | Circular receivables/payables problem statement and working-capital thesis | Partial | Customer evidence from real companies |
| Clear objective | Qatar pilot + GCC expansion objective documented | Ready | Refine with quantified pilot targets |
| Execution plan | 18-month phased roadmap drafted | Partial | Hiring plan, budget, milestone dates |
| Detailed technology roadmap | Web MVP, graph engine, approvals, audit, APIs, ERP integrations | Ready at concept level | Architecture diagram and delivery estimates |
| Validated concept | Public interactive PoC + tested netting engine | Strong PoC | Real-customer validation |
| Market readiness | Target segments identified | Early | 5–10 interviews, segment choice, market sizing |
| Robust business model | SaaS/API/success-fee hypotheses | Early | Pricing evidence from interviews |
| Monetization strategy | Multiple models identified | Early | Select one primary and one secondary model |
| Leadership team | Founder-led project | Partial | Founder CV + technical lead / delivery partner |
| Qatar launch relevance | Qatar pilot thesis and local validation plan | Partial | Local partner targets and legal/accounting scoping |

## Internal go/no-go threshold before submission

DebtLoop should ideally submit only after all of the following are true:

- working public PoC remains online;
- at least 5 structured customer interviews completed;
- at least 2 written pilot-interest statements / LOIs;
- one primary target segment selected;
- one primary pricing model selected;
- founder CV finalized;
- technical delivery responsibility clearly assigned;
- 18–24 month operating budget completed;
- funding request linked to milestones;
- Qatar legal/accounting validation plan documented.

These thresholds are internal preparation targets, not official QDB rules.
